                    AILYT - INSTALLATION QUICK STEPS
═══════════════════════════════════════════════════════════════════════════════

IMPORTANT: INSTALL NODE.JS FIRST!
If you haven't installed Node.js yet:
1. Download from: https://nodejs.org/ (LTS version)
2. Run the installer and follow the steps
3. Restart PowerShell after installation
4. Verify: node --version && npm --version

═══════════════════════════════════════════════════════════════════════════════
STEP 1: Navigate to Server Directory
═══════════════════════════════════════════════════════════════════════════════

cd "C:\Users\SIDDHARTH RAMOLA\OneDrive\Desktop\kanakpalkp\server"

═══════════════════════════════════════════════════════════════════════════════
STEP 2: Install Server Dependencies
═══════════════════════════════════════════════════════════════════════════════

npm install

⏳ Wait 2-3 minutes for installation to complete...

═══════════════════════════════════════════════════════════════════════════════
STEP 3: Create Server Environment File
═══════════════════════════════════════════════════════════════════════════════

Copy the content below into a file named ".env" in the server folder:

-----BEGIN .env CONTENT-----
PORT=5000
MONGODB_URI=mongodb://localhost:27017/ailyt
NODE_ENV=development
JWT_SECRET=ailyt_development_secret_key_change_in_production
FRONTEND_URL=http://localhost:3000
-----END .env CONTENT-----

═══════════════════════════════════════════════════════════════════════════════
STEP 4: Navigate to Client Directory
═══════════════════════════════════════════════════════════════════════════════

cd ../client

═══════════════════════════════════════════════════════════════════════════════
STEP 5: Install Client Dependencies
═══════════════════════════════════════════════════════════════════════════════

npm install

⏳ Wait 3-5 minutes for installation to complete...

═══════════════════════════════════════════════════════════════════════════════
STEP 6: Create Client Environment File
═══════════════════════════════════════════════════════════════════════════════

Copy the content below into a file named ".env" in the client folder:

-----BEGIN .env CONTENT-----
REACT_APP_API_URL=http://localhost:5000/api
-----END .env CONTENT-----

═══════════════════════════════════════════════════════════════════════════════
STEP 7: START THE APPLICATION
═══════════════════════════════════════════════════════════════════════════════

OPEN TWO SEPARATE TERMINALS:

TERMINAL 1 - Start Backend Server:
────────────────────────────────────────────
cd server
npm run dev

Expected output:
Server is running on port 5000
MongoDB connected successfully

TERMINAL 2 - Start Frontend:
────────────────────────────────────────────
cd client
npm start

Expected output:
Compiled successfully!
You can now view ailyt in the browser.
Local: http://localhost:3000

═══════════════════════════════════════════════════════════════════════════════

═══════════════════════════════════════════════════════════════════════════════

═══════════════════════════════════════════════════════════════════════════════
IF YOU GET ERRORS
═══════════════════════════════════════════════════════════════════════════════

Error: "Port 5000 already in use"
Fix: Change PORT=5001 in server/.env

Error: "npm not found"
Fix: Install Node.js from https://nodejs.org/

Error: "MongoDB connection failed"
Fix: Install MongoDB from https://www.mongodb.com/

Error: "Module not found"
Fix: Delete node_modules folder and run npm install again
