BACKEND API STRUCTURE
═══════════════════════════════════════════════════════════════════════════════

ENDPOINTS READY TO IMPLEMENT:

Courses API:
POST   /api/courses           - Create course
GET    /api/courses           - Get all courses
GET    /api/courses/:id       - Get single course
PUT    /api/courses/:id       - Update course
DELETE /api/courses/:id       - Delete course

Users API:
POST   /api/users/register    - Register new user
POST   /api/users/login       - Login user
GET    /api/users             - Get all users
GET    /api/users/:id         - Get user profile
PUT    /api/users/:id         - Update user profile

Projects API:
GET    /api/projects          - Get all projects
GET    /api/projects/featured - Get featured projects
GET    /api/projects/:id      - Get single project
POST   /api/projects          - Create project
PUT    /api/projects/:id      - Update project
DELETE /api/projects/:id      - Delete project

QUICK START COMMANDS
═══════════════════════════════════════════════════════════════════════════════

1. INSTALL DEPENDENCIES:
   
   Terminal 1 (Server):
   cd server
   npm install
   
   Terminal 2 (Client):
   cd client
   npm install

2. CREATE ENVIRONMENT FILES:
   
   server/.env
   server/.env.example (copy and fill values)
   
   client/.env
   client/.env.example (copy and fill values)

3. RUN DEVELOPMENT SERVERS:
   
   Terminal 1 (Server):
   cd server
   npm run dev
   
   Terminal 2 (Client):
   cd client
   npm start

4. OPEN IN BROWSER:
   http://localhost:3000

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Q: Port 5000 already in use?
A: Change PORT in server/.env to 5001

Q: npm install fails?
A: Delete node_modules and package-lock.json, then npm install again

Q: MongoDB not connecting?
A: Ensure MongoDB is running: mongod command in terminal

Q: CSS not loading?
A: Clear browser cache (Ctrl+Shift+Delete) and rebuild

Q: React app blank?
A: Check console for errors, ensure public/index.html exists
